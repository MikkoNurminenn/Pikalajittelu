# Pikalajittelu brand

**Less sorting. More adventure.**

Finnish: **Vähemmän lajittelua. Enemmän seikkailua.**

An orderly chest, made for a Nordic homestead. Brass framing conveys a useful,
well-made tool; dark timber and pine green connect it to the game setting.
Keep language practical: preview, organize, find, undo. Never imply that a mod
cannot lose items or that a release candidate has completed all testing.

## Assets

- [`emblem.png`](emblem.png): square raster chest mark, suitable for an avatar or mod icon.
- [`banner.png`](banner.png): landscape README and release cover with the wordmark.
- [`PROMPTS.md`](PROMPTS.md): generation prompts and provenance.

The banner is the primary lockup. The standalone chest is the compact mark.
Do not stretch either asset, add outlines, or place important content over them.
Keep at least 15% of the chest mark's width clear around it. At very small sizes,
prefer the chest silhouette rather than expecting the individual contents to read.
The artwork is raster, not a vector logo or an identified commercial font.

## Colour

| Role | Colour |
| --- | --- |
| Forest background | `#101916` |
| Pine surface | `#152B26` |
| Brass accent | `#E8BE6C` |
| Warm ivory text | `#F3ECD8` |
| Muted sage | `#AAB8AF` |

Use ivory for body text and gold for a single primary action or emphasis. Gold
buttons should have dark text. Keep decoration quiet and leave room around content.
The generated artwork contains natural texture variations around these palette targets.

## Type and voice

The banner's engraved serif wordmark is a fixed image. For companion headings,
use a readable, sturdy serif; for instructions and UI, use a familiar sans-serif
such as Segoe UI or the game's own font. Avoid decorative runic body text.

Short instructions should say what happens: “Preview transfer”, “Confirm”, “Find
items”, “Undo last transfer”. Always label release candidates and distinguish
tested behavior from remaining validation. This is an independent community
identity, not the official Valheim logo.
